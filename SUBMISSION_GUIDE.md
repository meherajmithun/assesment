# Assignment delivery guide

## Before the client submits

1. Replace every `[ADD STUDENT NAME]` and `[ADD STUDENT ID]` placeholder.
2. For TEC206, run the tests and personally demonstrate the menu program.
3. For TEC303, open the project in Android Studio, sync, run it in an emulator, and
   record the required video using `VIDEO_SCRIPT.md` as a guide.
4. Review both solutions and ensure the student can explain the inheritance, validation,
   report rules, and Intent data passing.
5. Follow KBS Level 2 AI referencing requirements and include the full chat transcript.
