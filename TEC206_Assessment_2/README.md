# Bookstore Inventory

This beginner-friendly Python program manages fiction and non-fiction books.
Books are stored in a list while the program is running.

## Main Classes

- `Book` stores the title, author, price, quantity, and type.
- `FictionBook` adds a genre.
- `NonFictionBook` adds a subject.

## Menu

1. Add Fiction Book
2. Add Non-Fiction Book
3. Display Books
4. Update Price
5. Update Quantity
6. Exit

## Run

```bash
cd codebase
python3 bookstore_inventory.py
```
